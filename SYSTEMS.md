# SYSTEMS.md: Map of interconnected components

Keep this current. Rules for using it are in [AGENTS.md](AGENTS.md) (one hop only, each file once per task).

## Components

| ID | File(s) | Role |
|---|---|---|
| SERVER | `server.py` (entry point) + `gloan/` package | Stdlib HTTP server, split by job (below) |
| SERVER-config | `gloan/config.py` | Paths, limits, regexes, logger |
| SERVER-storage | `gloan/storage.py` | `photos.json` + image files: validation, cleaning, scan, `available_rows` (skips index rows with no file) |
| SERVER-query | `gloan/query.py` | Filter/sort/page for `GET /api/photos` (`SORT_KEYS`) |
| SERVER-auth | `gloan/auth.py` | Signed owner tokens, IP normalising, login-lockout state |
| SERVER-handler | `gloan/handler.py` | HTTP routes (`Handler`) |
| SERVER-cli | `gloan/cli.py` | Flags, password prompt, start-up |
| SERVER-thumbtool | `gloan/thumbtool.py` | Launches `tools/make_thumbnails.py` in the background on owner request and tracks status |
| THUMB-TOOL | `tools/make_thumbnails.py`, `tools/requirements.txt` | Standalone Pillow utility that generates 480px JPEG tiles in `data/thumbs/` and records `thumb` in `photos.json` |
| TESTS | `tests/test_gloan.py` | Unit, integration, thumbnail-tool, and `index.html` JS syntax test suite (`python3 -m unittest discover -s tests -v`) |
| FRONTEND | `index.html` | Single-page gallery and owner UI; talks to SERVER via the `API` object |
| DATA | `data/photos/`, `data/thumbs/`, `data/photos.json` | Image files and metadata (title, tags, story); path set by `GLOAN_DATA` |
| DOCKER-PROD | `Dockerfile`, `.dockerignore` | Production image (Cloud Run); copies `server.py`, `gloan/`, `tools/` and `index.html`, and installs `tools/requirements.txt` |
| DOCKER-DEBUG | `Dockerfile.debug`, `docker-compose.debug.yml` | Local debug container with debugpy on 5678, site on 8000 |
| VSCODE | `.vscode/launch.json`, `.vscode/tasks.json` | F5 starts DOCKER-DEBUG and attaches debugger |
| DEPLOY | `deploy.sh` | Cloud Run + Cloud Storage + Secret Manager deploy |
| DOCS | `README.md`, `AGENTS.md`, `SYSTEMS.md` | Documentation |

## Links (if you change the left side, check the right side)

| FRONTEND fetch calls | SERVER matching route and auth requirement | Contract |
| New runtime file or package needed by the app (e.g. a new module in `gloan/` is covered, a new top-level file is not) | DOCKER-PROD `COPY`; DOCKER-DEBUG compose volumes; VSCODE `pathMappings`; `.dockerignore` | Only listed files enter the image |
| Python version or dependencies | DOCKER-PROD and DOCKER-DEBUG base images; README | Keep images in sync |

| Any new component, or renamed or removed file | This file | Keep the map accurate |

## Testing linked systems

- Run unit & JS syntax tests after every change: `python3 -m unittest discover -s tests -v`.
- Start with F5 (or `docker compose -f docker-compose.debug.yml up -d --build`) and open http://localhost:8000.
- Run the full suite inside the container (which includes Pillow): `docker exec gloan-debug python3 -m unittest discover -s tests -v`.
- Check: gallery loads, owner login (`debugpassword`), upload, edit, delete, rescan, thumbnail generation, logout/expired session.
- Production image: `docker build -t gloan-test .` should succeed.
